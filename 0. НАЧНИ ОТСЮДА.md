# Начни отсюда

Это готовая папка проекта для работы с Claude Code. В ней уже разложено, где лежит стратегия, продукты,
контент и доступы, и написаны правила, по которым Claude работает. Благодаря этому Claude в каждом новом
чате сразу понимает проект, а не знакомится с ним заново.

Подходит для любого проекта: ИИ-блогер, личный блог, бот, магазин.

## Запуск — три шага

1. **Переименуй папку** в название своего проекта и положи туда, где хранишь рабочие файлы
   (например, в «Документы»). В «Загрузках» не оставляй.
2. **Открой папку в Claude Code** (в VS Code: «Файл → Открыть папку», затем панель Claude).
3. **Напиши: «Настрой проект».** Claude задаст вопросы о проекте — что продаёшь, кому, где, какие
   площадки — и сам заполнит все файлы. Это 15–20 минут. Отвечать можно голосом и своими словами.

Копируй папку целиком: в ней есть скрытые файлы (`.gitignore`, `.local`), они нужны.
На Mac их видно в Finder по Cmd + Shift + точка.

## Что где лежит

| Папка или файл | Что внутри |
|---|---|
| `CLAUDE.md` | Главный файл: правила для Claude и краткое описание проекта. Claude читает его в начале каждого чата |
| `1. Стратегия/` | Кому продаём, что, через какой канал и к какой цели идём |
| `2. Исследования/` | Рынок, конкуренты, разборы чужого контента |
| `3. Продукты/` | Каждый продукт — в своей папке со всеми материалами |
| `4. Контент/` | Голос и образ, смыслы, планы недель, сценарии, посты, сторис, карусели |
| `АРХИВ — история работы/` | Память проекта: текущее состояние, хроника по дням, ошибки, решения |
| `ДОСТУПЫ — карта (без значений).md` | Список всех сервисов и аккаунтов — без паролей |
| `.local/доступы/` | Сами пароли и ключи. Лежат только на твоём компьютере |
| `tools/` | Скрипты бэкапа. Запускает их Claude |

## Фразы на каждый день

- **«Что у нас по проекту?»** — Claude перескажет состояние и открытые хвосты.
- **«Запомни: …»** — решение или правило попадёт в память проекта и не потеряется.
- **«Что мы решили про …?»** — Claude найдёт в памяти и хронике.
- **«Сделай бэкап»** — всё сохранится в твой приватный репозиторий GitHub.
- **«Что думаешь?»** — Claude обязан ответить честно, с возражениями, а не поддакивать.

## Три правила

1. **Пароли не пиши в чат.** Клади их в файл `.local/доступы/ДОСТУПЫ.md` — он не уходит в интернет.
2. **Решил что-то важное — скажи «запомни».** Иначе в следующем чате Claude об этом не узнает.
3. **Заканчивай рабочий день бэкапом.** Если компьютер потеряется, проект поднимется из GitHub за
   20 минут — как именно, написано в `ВОССТАНОВЛЕНИЕ.md`.

## Если что-то меняется

Новый продукт, новая площадка, новое правило — просто скажи об этом Claude. Он обновит `CLAUDE.md` и
состояние проекта сам. Руками править `CLAUDE.md` тоже можно: это обычный текстовый файл.
