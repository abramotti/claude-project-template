# Продукты

**Одна папка — один продукт.** Всё, что относится к продукту, лежит внутри его папки: описание, материалы,
лендинг, программа, код. Ничего не кладём в `3. Продукты/` мимо папки продукта.

Новый продукт — скопировать `_ШАБЛОН продукта/`, переименовать и заполнить карточку `README.md`.
Затем добавить продукт в таблицу «Продукты» в `CLAUDE.md` и в `АРХИВ — история работы/03-СОСТОЯНИЕ.md`.

У продукта с кодом (бот, сайт, сервис) в папке лежит своя `CLAUDE.md`: как устроено, как запускать,
как выкатывать и как откатиться. Её читают перед любой правкой.

Статусы: идея · в работе · продаётся · на паузе · закрыт.
