# Контент

Всё, что публикуем. Сначала опоры — кто говорит и что несём, потом план, потом готовые единицы по форматам.

| Что | Где | Как называть файлы |
|---|---|---|
| Кто говорит: тон, история, образ | `ГОЛОС И ОБРАЗ.md` | — |
| Какие смыслы несём | `НАРРАТИВЫ.md` | — |
| План по дням | `Планы недель/` | `ГГГГ-ММ-ДД.md` — дата понедельника |
| Сценарии роликов | `Сценарии/` | `ГГГГ-ММ-ДД-тема.md`, без даты — `тема.md` |
| Посты | `Посты/` | так же |
| Сторис | `Сторис/` | так же; серия на день — один файл |
| Карусели | `Карусели/` | так же; слайды внутри по порядку |
| Чужие удачные примеры, банк заголовков и хуков | `Референсы/` | `заголовки.md`, `хуки.md`, `разбор-имя.md` |

## Статусы

У каждой единицы контента в первой строке файла — статус: **запланирован · готов · выложен**.
У выложенного — дата и ссылка на публикацию, а через несколько дней — цифры: просмотры, реакции, заявки.

## План недели — формат

```
# Неделя с ДД.ММ.ГГГГ

Фокус недели: к чему подводим аудиторию.

| День | Площадка | Формат | Тема и смысл | Файл | Статус |
|---|---|---|---|---|---|
| Пн | | | | | запланирован |
```

## Порядок работы над единицей

1. Тема берётся из плана недели. Нет в плане — сначала внести.
2. Открыть `ГОЛОС И ОБРАЗ.md`, `НАРРАТИВЫ.md` и `1. Стратегия/АУДИТОРИЯ.md`.
3. Согласовать с владельцем хук и главную мысль, потом писать целиком.
4. Сохранить в папку формата, поставить статус, обновить строку в плане недели.
