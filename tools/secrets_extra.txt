# Файлы ВНЕ папки проекта, которые тоже нужно положить в зашифрованный архив доступов.
# По одному пути на строку, «~» — домашняя папка. Строки с «#» — комментарии.
# Папка .local/ и файлы .env проекта попадают в архив сами, их здесь указывать не нужно.
#
# Примеры (убери «#», если такой файл есть и нужен проекту):
# ~/.ssh/id_ed25519
# ~/.ssh/id_ed25519.pub
# ~/.ssh/config
