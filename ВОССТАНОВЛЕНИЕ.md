# Восстановление проекта, если компьютер потерян

Всё нужное лежит в репозитории: документы, контент, код, память и история работы.
Доступы (пароли, ключи) — в `Секреты (зашифровано)/доступы.tar.gz.enc`, открываются **паролем владельца**.

## На новом компьютере (≈20 минут)

1. Поставить git, GitHub CLI и VS Code с расширением Claude Code. На Mac, в Терминале:
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   brew install git gh
   ```
   На Windows — Git for Windows (в нём есть Git Bash, скрипты из `tools/` запускать в нём) и GitHub CLI.
2. Войти в GitHub: `gh auth login` — аккаунт **[ЗАПОЛНИТЬ: аккаунт GitHub]**.
3. Скачать проект:
   ```bash
   gh repo clone [ЗАПОЛНИТЬ: аккаунт/репозиторий] "[ЗАПОЛНИТЬ: название папки]"
   cd "[ЗАПОЛНИТЬ: название папки]"
   ```
4. Расшифровать доступы и вернуть их на место:
   ```bash
   bash tools/secrets_unpack.sh --restore
   ```
   Скрипт спросит пароль архива, разложит `.local/доступы/` и файлы `.env` по местам в проекте, а остальное
   (ssh-ключи и другие файлы с компьютера) оставит в папке `~/Доступы — <название проекта>/` — разложить руками.
5. Открыть папку в VS Code, запустить Claude и сказать: «прочитай CLAUDE.md и состояние проекта». Всё.

## Без компьютера (телефон)

claude.ai/code → репозиторий проекта. Значения доступов там берутся из переменных окружения
(см. `ДОСТУПЫ — карта (без значений).md`). Всё, что требует файлов с компьютера, оттуда недоступно.

## Как поддерживается свежим

- `tools/backup_all.sh` — весь проект в GitHub. Claude запускает в конце каждой сессии и по просьбе
  «сделай бэкап».
- `tools/secrets_pack.sh` — пересобрать зашифрованные доступы. Запускает **владелец** (пароль вводит сам)
  после смены любого пароля или ключа. Затем Claude пушит.
