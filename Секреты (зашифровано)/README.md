# Секреты (зашифровано)

Здесь лежит `доступы.tar.gz.enc` — зашифрованная копия всех паролей и ключей проекта.
Её можно хранить в GitHub: без пароля владельца она не открывается.

- Создать или обновить: `bash tools/secrets_pack.sh` — запускает владелец, пароль вводит сам.
- Открыть: `bash tools/secrets_unpack.sh` — подробности в `ВОССТАНОВЛЕНИЕ.md`.

Пароль архива нигде в проекте не записан. Потерян пароль — архив не восстановить.
